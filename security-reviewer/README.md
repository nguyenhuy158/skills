# Security Reviewer Skill

This skill provides a comprehensive security code review based on the OWASP Top 10 vulnerabilities.

## Usage

Load this skill when you want to audit your code for security issues.

## Features

*   Checks for Injection flaws (SQL, Command, etc.)
*   Identifies Broken Authentication and Session Management
*   Detects Sensitive Data Exposure
*   Highlights XML External Entities (XXE)
*   Finds Broken Access Control
*   Warns about Security Misconfiguration
*   Checks for Cross-Site Scripting (XSS)
*   Identifies Insecure Deserialization
*   Flags Using Components with Known Vulnerabilities
*   Notifies about Insufficient Logging & Monitoring

## Files

*   `SKILL.md`: The core instructions for the agent.
